>
> 기록 원칙: 문제를 한 번에 풀기보다 입력 → RGB → 밝기 → 평균 임계값 → 0/1 변환 → 출력 → 테스트 순서로 잘게 나누어 이해한다.

## Q001
### 현재 내가 이해한 내용

### AI에게 한 질문
문제 2가 근본적으로 원하는 것이 무엇인가?
### AI 답변에서 이해한 핵심
컬러 이미지를 밝기 값으로 바꾸고, 전체 평균 밝기를 기준으로 각 픽셀을 0 또는 1로 분류하는 문제이다.
### 내가 직접 해본 것
