# AI 학습 과정 기록

## Q001

### 현재 내가 이해한 내용
이미지는 여러 줄의 0과 1로 표현될 수 있다는 것까지 이해했다.

### AI에게 한 질문
2차원 이미지에서 행과 열은 무엇인가요?
코드는 말하지 말고 개념만 설명해 주세요.

### AI 답변에서 이해한 핵심
이미지는 가로와 세로 방향으로 값이 배치되어 있다.
세로 위치를 행(row), 가로 위치를 열(column)이라고 한다.
Python에서는 `image[행][열]` 형태로 특정 픽셀에 접근할 수 있다.

### 내가 직접 해본 것
4×4 이미지에서 첫 번째 행과 첫 번째 열의 위치를 확인했다.

### 결과
이미지의 각 값은 행과 열의 위치로 찾을 수 있다는 것을 이해했다.

### 다음에 궁금한 것
4×4 이미지에서 왼쪽 위 2×2 영역은 어떤 좌표인가?

## Q002

### 현재 내가 이해한 내용
이미지의 한 픽셀은 `image[행][열]`처럼 행과 열의 좌표로 찾을 수 있다.

### AI에게 한 질문
4×4 이미지에서 왼쪽 위 2×2 영역은 어떤 좌표인가요?
코드는 작성하지 말고 좌표만 이용해서 설명해 주세요.

### AI 답변에서 이해한 핵심
Python의 인덱스는 0부터 시작한다.
따라서 4×4 이미지의 왼쪽 위 2×2 영역은 행 0~1, 열 0~1에 해당한다.
좌표로 쓰면 `(0,0)`, `(0,1)`, `(1,0)`, `(1,1)`이다.

### 내가 직접 해본 것
아직 직접 확인 전. 아래 4×4 예제에서 네 좌표의 값을 직접 찾아본다.

```text
0000
0011
0011
1111
```

### 결과
직접 확인 후 기록한다.

2×2 영역의 값이 모두 같은지 사람은 어떤 순서로 확인하면 되는가?
