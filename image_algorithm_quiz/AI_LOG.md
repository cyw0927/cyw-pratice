# AI 학습 과정 기록 — 문제 2

> 담당 범위: 문제 2 `컬러 이미지의 임계값을 계산하고 흑백 이미지 만들기`
>
> 문제 2는 질문 수가 부족하지 않도록 **Q001~Q050, 총 50단계**로 나누었다.
> 단순히 같은 질문을 반복하지 않고 `문제 이해 → RGB → 밝기 → 입력 처리 → 저장 → threshold → 흑백 변환 → 함수화 → 실행 → 테스트 → 복잡도` 순서로 이어지도록 구성했다.

## Q001
