# AX 2기 이미지 알고리즘 퀴즈

이미지 데이터를 직접 다루는 알고리즘 학습 과제용 폴더입니다.

## 파일 구성

- `problem01.py` : 흑백 이미지 압축 문제
- `problem02.py` : 컬러 이미지 임계값 계산 및 흑백 변환 문제
- `AI_LOG.md` : AI와 학습한 단계 기록
- `SOLUTION_GUIDE.md` : 문제 해결 과정과 최종 설명서

## 진행 방법

1. `AI_LOG.md`에 학습 과정을 한 단계씩 기록합니다.
2. 문제 1을 작은 단계로 나누어 이해한 뒤 직접 구현합니다.
3. 문제 2도 같은 방식으로 진행합니다.
4. 테스트 결과와 시행착오를 `SOLUTION_GUIDE.md`에 정리합니다.
5. 최종 코드는 본인이 이해한 뒤 완성합니다.
