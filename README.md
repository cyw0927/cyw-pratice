# AX 2기 이미지 알고리즘 퀴즈

현재 이 저장소에서는 **문제 2: 컬러 이미지의 임계값을 계산하고 흑백 이미지 만들기**를 중심으로 학습 기록, 실행 코드, 테스트 결과, 최종 설명서를 정리하고 있다.

## 파일 구성

- `problem02.py` : 실제 제출용 문제 2 실행 코드
- `problem02_learning.ipynb` : 문제 2를 75개의 질문으로 나눈 초상세 학습 노트
- `AI_LOG.md` : AI에게 단계적으로 질문하면서 이해가 어떻게 진행됐는지 기록
- `SOLUTION_GUIDE.md` : 문제 설명, 핵심 개념, 세부 단계, 수도코드, 최종 코드, 예제 추적, 시행착오, 테스트, 복잡도, 대안, AI 학습 정리
- `TEST_RESULTS.md` : 문제 2의 테스트 입력·예상 결과·실제 결과·PASS/FAIL 기록
- `problem01.py` : 문제 1 관련 파일

## 문제 2 전체 흐름

```text
RGB 입력
→ 문자열 분리
→ R, G, B 정수 변환
→ brightness = (R + G + B) // 3
→ brightness_map 저장
→ 전체 평균 threshold 계산
→ brightness >= threshold 비교
→ 1 또는 0 변환
→ threshold와 흑백 행 출력
```

## 실행 방법

PowerShell에서 저장소 폴더로 이동한 뒤 실행한다.

```powershell
python problem02.py
```

예제 입력:

```text
3 3
255,255,255 200,200,200 0,0,0
120,120,120 60,60,60 30,30,30
255,0,0 0,255,0 0,0,255
```

정상 출력:

```text
102
110
100
000
```

## Jupyter Notebook 사용

`problem02_learning.ipynb`는 각 질문마다 설명 셀과 실제 실행 가능한 코드 셀을 함께 둔다. 각 코드 셀은 가능한 한 앞 셀에 의존하지 않도록 작성되어 있으므로 원하는 질문의 코드만 따로 실행해도 확인할 수 있다.

VS Code에서 `.ipynb`를 열고 Python 커널을 선택한 뒤 셀 왼쪽의 실행 버튼을 누른다. 전체를 확인하려면 `Run All`을 사용할 수 있다.
